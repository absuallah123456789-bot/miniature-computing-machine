# Piece images

A placeholder CC0 set generated by `scripts/gen_pieces.py` lives here. Replace with your own PNGs, named exactly:

```
whitepawn.png  whiteknight.png  whitebishop.png  whiterook.png  whitequeen.png  whiteking.png
blackpawn.png  blackknight.png  blackbishop.png  blackrook.png  blackqueen.png  blackking.png
```

If your files are named differently (e.g. `whiteN.png`), change the one-line `pieceSrc()` function at the top of `ui/js/app.js`.
